# Arte conceitual minimalista

## Proveniência e licença

As cinco imagens desta pasta foram **geradas por IA** com o gerador de imagens da OpenAI (ChatGPT / gpt-image). Os arquivos PNG mantêm os metadados C2PA de proveniência gravados pela ferramenta. Não os remova. Elas são conceitos de arte para orientar o desenho, não arte final do jogo. Como a autoria é de uma ferramenta de IA e não há concessão de licença explícita, não afirme autoria humana exclusiva sobre elas. Veja também o [aviso de terceiros](../../../THIRD_PARTY_NOTICES.md).

Os prompts abaixo são os prompts exatos das imagens escolhidas, mantidos em inglês. As inspeções são visuais: não certificam cores em nível de pixel nem a ausência de semelhança com todo jogo existente. Os quatro arquivos horizontais têm 1672 × 941 pixels: visualmente 16:9, mas não exatamente 16:9. O quadrado tem 1254 × 1254.
